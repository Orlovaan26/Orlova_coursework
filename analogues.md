# Анализ аналогов

Для создания программного средства необходимо изучить представленные аналоги и выделить их основные недостатки и преимущества. В качестве исследуемых аналогов были выбраны программные продукты, связанные с организацией спортивных мероприятий, регистрацией участников и управлением волонтёрами.

## Проспорт40

Официальный агрегатор любительских спортивных мероприятий Калужской области. Реализует единую афишу, онлайн-регистрацию с оплатой слотов, личный кабинет с бонусными баллами, передачу слота, регистрацию на флагманские старты.

**Преимущества:** единая афиша спортивных событий региона, онлайн-регистрация с оплатой слотов, личный кабинет с системой бонусных баллов, возможность передачи слота другому участнику, регистрация на флагманские старты.

**Недостатки:** отсутствует роль «Волонтёр», QR-код используется только для первичной регистрации, подтверждение явки происходит вручную.

## Eventixa

WordPress-плагин для управления событиями. Реализует календарь, регистрацию, QR-билеты, сканер QR-кода, лимиты мест, лист ожидания, PDF-билеты.

**Преимущества:** генерация QR-билетов, сканирование QR-кода для подтверждения явки, управление лимитами мест, лист ожидания при заполнении, формирование PDF-билетов.

**Недостатки:** отсутствует роль «Волонтёр», нет спортивной специфики, ограничен WordPress, нет городской афиши и русской локализации, нет аналитики для организаторов.

## e-Champs

Российская цифровая платформа для управления спортивными организациями и соревнованиями. Реализует цифровой паспорт спортсмена, календарь мероприятий, онлайн-регистрацию, реестры тренеров и судей, документооборот, кабинет организатора.

**Преимущества:** цифровой паспорт спортсмена с накоплением статистики, календарь мероприятий с приёмом заявок и онлайн-оплатой, реестры тренеров и судей, автоматизация документооборота, отдельная веб-страница для каждого мероприятия, кабинет организатора.

**Недостатки:** отсутствует роль «Волонтёр», фокус на соревновательной деятельности и документообороте, нет QR-верификации явки.

## Кто Куда

Российское мобильное приложение для организации любительского спорта и городских событий. Реализует афишу городских событий, поиск игр и тренировок, запись в один клик, формирование команд, работу в 14 городах.

**Преимущества:** афиша городских событий с фильтрацией, поиск игр и тренировок по геолокации, формирование команд из незнакомых людей, возможность предложить своё событие.

**Недостатки:** отсутствует роль «Волонтёр», нет личного кабинета организатора, фокус на любительских играх, мобильное приложение, нет QR-верификации.

## Crosswater Digital

Российская SaaS-платформа для управления спортивными мероприятиями. Реализует онлайн-регистрацию, личные кабинеты, управление слотами и квотами, аналитику.

**Преимущества:** онлайн-регистрация участников, личные кабинеты для участников и организаторов, управление слотами и квотами, аналитика по регистрациям и заполняемости.

**Недостатки:** нет роли «Волонтёр», только коммерческие старты, высокая стоимость, недоступная для муниципального уровня.

## Вывод

Ни один из рассмотренных аналогов не объединяет все три роли — участника, организатора и волонтёра — в одном бесплатном веб-приложении с городской афишей и QR-верификацией. «Проспорт40» — прямой локальный конкурент, но не решает задачу управления волонтёрами и подтверждения явки через QR-код. Eventixa реализует сканирование QR-кода, но не имеет волонтёров и спортивной специфики. Остальные аналоги либо не имеют роли «Волонтёр», либо ориентированы на другие сегменты рынка.
